# Prism · 棱镜

把论文拆解成结构、创新和证据，把零散阅读连接成自己的研究视野。

**技能名：** `paper-prism`  
**作者：** 用户自制（GitHub：[@15016623369a-spe](https://github.com/15016623369a-spe)）  
**版本：** 2.1.1

按你的需求编写的个人技能：帮助读懂英文论文，积累文献和术语，持续比较新旧研究，并在需要时完成精简、重逻辑的组会汇报、PPT 和绘图。保留原有架构梳理、研究总结、创新点核查和可追溯阅读卡功能。

## 功能说明

| 功能 | 实际得到什么 | 默认行为 |
|---|---|---|
| 中文精读与架构拆解 | 原文章节的论证作用，以及方法模块、输入输出、训练/推理流程 | 完整精读时生成 |
| 总结与创新点 | 问题、方法、结果、成立条件；区分作者主张、证据与阅读者判断 | 关键结论有原文定位 |
| 英语专业词汇 | 英文/缩写、中文、通俗解释、本文语境、出处 | 只展开本次新词，不堆通用单词 |
| 跨论文词汇去重 | 累积词库、稳定 T 编号、别名和历次出处 | 下篇同词义不重复解释，可随时要求复习 |
| 中文阅读指南 | 背景桥接、阅读顺序、必读图表、关键公式解释、易误读处和自测 | 完整精读附约 30–45 分钟首轮路线 |
| 相关文献推荐 | 约 3–5 篇真实相关论文，说明用途、阅读顺序、联系和核查范围 | 自动联网核验；离线时标为待核验候选 |
| 本地文献库和对比 | 稳定 P 编号、新旧论文共同点、差异、互补、冲突及证据缺口 | 入库后读取实际旧卡比较 |
| 组会汇报 | 清晰论证主线、逐页规划、简短讲稿和有依据的答疑 | 按需，未指定时按中文 10 分钟准备 |
| 实际 PPT | 与讲稿一致的演示文稿，关键证据图表与来源、必要限制 | 明确要求 PPT 时自动制作并检查，不只给大纲 |
| 论文式数学公式 | 真正的上下标、分数、帽符号、粗体向量和数学字体；保留公式源 | 自动检查并按需安装 MathJax，渲染后逐页核对 |
| 绘图 | 实验数据图、方法/流程图、文献关系图；原图提取或重新绘制 | 按需，支持实际工具可导出的 PNG/SVG/PDF 等 |
| 必要工具自动调用 | PDF 提取/查看、文件读写、检索、去重脚本、绘图、PPT 制作及检查 | 任务需要时主动执行，不停在操作建议 |

## 怎样使用

日常直接提供 PDF、DOI、真实论文链接或正文，再自然描述需求；也可显式调用 `$paper-prism`。

### 英文精读与积累

```text
请使用 $paper-prism 精读这篇论文，沿用已有文献库。
提取本次新专业词汇，旧词不重复解释，生成中文阅读指南，
保存阅读卡，并与库内相关论文比较，推荐后续阅读。
执行必要步骤时自动调用合适的工具。
```

### 阅读时卡住 / 词汇复习

```text
请使用 $paper-prism，解释这篇论文第 4 页的公式和难句，
先用中文讲概念，再解释英文术语和符号。这里的旧词也请再讲一遍。
```

```text
请使用 $paper-prism，把词库里的 T0003 标为已掌握，
将 T0007 标为待复习，按我最近读的论文给一份简短复习表。
```

“已经出现过”不会自动等于“你已经掌握”。第一次出现默认标注，后续不重复展开；需要复习时一句话即可重新解释。别名去重需核实上下文，同一个缩写不同含义会分别保留。默认标注发生在中文笔记/指南中，不直接改原 PDF；若要 PDF 批注请明确提出。

### 调整阅读路线和推荐

```text
请使用 $paper-prism，给我 20 分钟理解这篇论文的阅读指南。
我对卡尔曼滤波有基础，但不了解 Koopman 理论。
推荐 3 篇补背景的论文，并核验真实来源。
```

### 组会汇报与实际 PPT

```text
请使用 $paper-prism，基于 P0001 做一份 10 分钟组会汇报。
生成 8 页 PPT（含封面）和简短逐页讲稿，重点讲问题、方法创新、
实验是否支持结论，以及局限。内容精简但逻辑完整。
自动调用必要的演示文稿和绘图工具，并检查实际文件。
```

未指定时长/受众/页数时，按中文 10 分钟、同方向未读本文的听众、约 6–8 页总页数准备。你给出的要求、模板优先。只说“给大纲”就生成大纲；说“制作 PPT”会实际生成文件。普通读论文不会顺便制作 PPT。

### 数据图与方法图

```text
请使用 $paper-prism，把这篇论文的方法梳理成训练/推理流程图，
标明哪些模块已知、哪些需要学习，导出 PNG 和可编辑图源。
```

```text
请使用 $paper-prism，根据原文表格绘制精度与耗时对比图，
保留数据、单位、实验条件和来源，用于组会 PPT。
```

没有原始数据时优先使用原图，不凭空生成曲线或误差棒。不同论文实验条件不一致时会解释可比性，避免图形误导。数据图采用科研绘图能力；架构图采用流程/关系图能力，工具分工不同。

### 只完成需要的部分

```text
请使用 $paper-prism，只在聊天里解释方法和新术语，
这次不保存文件，不联网推荐。
```

## 文件与长期使用

优先沿用你明确指定或当前项目已使用的库，检查 `outputs/literature-library/` 与 `literature-library/`，避免每次创建空库。没有已有库时按环境规定的交付位置建立。换项目或新聊天时提供库路径，可继续读取文件积累，无需依赖聊天记忆。

```text
literature-library/
  library.json              论文登记，兼容 v1
  index.md                  阅读卡索引
  notes/                    阅读卡与历史修订
  records/                  文献登记输入
  comparisons/              跨论文比较报告
  glossary/terms.json        术语、别名、词义、掌握状态、出处
  glossary/index.md          可查询词库
  glossary/batches/          每篇术语输入
  guides/                   中文阅读指南
  recommendations/          核验推荐 / 待核验候选
  presentations/            按需汇报稿和实际 PPT
  figures/                  按需图片、源数据/图源、来源说明
```

新增目录按需建立。升级不会清空旧库、改写旧阅读卡或把所有旧论文自动标成已完成新功能。需要给旧论文补词汇/指南时，直接要求“给 P0001 补充词汇和阅读指南”。跨库词汇不会自动共享；需要共享时指定统一的库或明确要求迁移。

## 工具如何自动工作

技能会依据实际任务发现并调用当前环境提供的工具，不写死某个平台的 API：

- PDF：提取正文，检查关键图表/公式；扫描件在有可用 OCR 时识别。
- 文献和词库：读文件、运行本地登记/去重脚本、保存并检查记录与索引。
- 推荐：搜索并访问真实原始来源，注明已读摘要还是全文。
- 绘图：发现可用运行时，调用科研绘图/图形渲染能力，导出后查看实际图像。
- PPT：使用当前可用的演示文稿技能/工具，生成、渲染、查看、修正实际文件。
- 数学公式：自动检查依赖，缺少时安装免费 MathJax 到独立目录，将 LaTeX 排成真实公式，保留 SVG、MathML 和来源。PPT 优先原生公式，工具不支持时用清晰矢量图，明确其可编辑范围。

技能通过模型调用真实工具，并提供可执行的公式安装/渲染脚本。你已授权：数学公式依赖缺失时主动安装，不再只给操作步骤；安装仍遵循平台权限。不会默认购买服务、安装其他软件或上传本地论文，也不保证所有环境都有同样的导出能力。缺少能力会完成可行部分，并明确哪个步骤/文件未完成。

## 安装与自定义

仓库中的整个目录就是技能。克隆时使用 `paper-prism` 作为文件夹名：

```sh
git clone https://github.com/15016623369a-spe/paper-prism.git ~/.codex/skills/paper-prism
```

配置了 `CODEX_HOME` 时，请放到对应的 `skills/paper-prism/`。也可下载仓库 ZIP，解压后将根目录改名为 `paper-prism` 并放入个人技能目录。目标目录已经存在时先备份，不要覆盖自定义内容。安装后在新会话中使用 `$paper-prism`。

从旧版 `literature-reader` 更名时，保留原有项目文献库；确认新目录可用后，将旧技能目录移到技能目录之外备份，避免重复加载。公式工具仍兼容原缓存 `~/.cache/literature-reader/mathjax` 与 `LITERATURE_READER_MATH_DIR`，无需因更名重复安装。


完整技能目录放在个人技能目录 `~/.codex/skills/paper-prism/`（配置了 `CODEX_HOME` 时使用其 `skills/`）。分享使用 `paper-prism-v2.1.1.zip`，包中不含你的论文、阅读卡或词库。文献库需另行备份/迁移。

- `SKILL.md`：触发方式、默认工作流、自动工具调用。
- `README.md`：这份功能说明与调用示例。
- `references/english-reading.md`：词汇、阅读指南、去重和复习规则。
- `references/recommendations.md`：推荐与来源核验。
- `references/presentation.md`：汇报和 PPT 的逻辑与交付。
- `references/figures.md`、`references/tools.md`：绘图和工具调度。
- `assets/`：阅读卡、指南、对比报告、汇报规划模板。
- `scripts/library.py`、`scripts/glossary.py`：论文与词汇登记。
- `references/equations.md`、`scripts/setup_equations.py`、`scripts/render_equations.mjs`：公式排版、独立安装与实际渲染。

登记脚本仅需 Python 3.10+ 标准库，不用模型 API key。公式脚本使用 Node.js 与固定版本 MathJax，按需自动安装，安装后可离线渲染。提词、阅读和判断由模型完成，脚本负责可靠保存、去重和索引。PPT/绘图依赖当前环境相应能力，实际执行时按需加载相关技能，无须每次都加载全套。

## 证据边界与验证

摘要/部分文本分析不会冒充全文精读；推荐的未读论文不会冒充已入库精读文献；“首次”等创新性判断需外部核查；组会精简不会删去影响结论的条件。

版本 2.1 新增公式格式检查、独立安装与真实渲染流程。公式工具和输出应实际验证后才报告完成；以前的阅读卡、词库和汇报文件不会因此被删除。

版本 2.1.1 将技能命名为 **Prism · 棱镜**，调用名改为 `$paper-prism`；功能与文献库格式保持兼容。仓库仅包含技能指令、模板和脚本，不包含个人论文、阅读卡、词库或运行依赖。

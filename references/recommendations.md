# 相关文献推荐

完整精读默认给 3–5 篇左右，数量按真正相关的资料调整；用户指定数量/方向/年份时优先。按用途选择：必要背景、最接近的方法/基线、可互补的方向或后续进展。不是按引用数堆热门论文，也不强行包含“最新”。

1. 从当前论文问题、关键模块、相关工作及用户研究方向构建检索词，库内已有相关文献可以优先建议。
2. 自动调用实际可用的学术检索/浏览能力。核对出版商、会议官网、arXiv 或作者公开原文的题名、作者、年份、标识符与版本，访问实际摘要/全文；区分发布时间与检索日期。
3. 每篇解释与当前论文的具体联系、推荐理由、应重点读的部分、推荐顺序与已核查范围。只读摘要时只根据摘要推荐，不评价未读实验细节。
4. 标明“库内已读 / 库外已核验摘要 / 库外已读全文 / 待核验候选”。未读推荐不登记为完整阅读卡，不据此产生跨论文深度比较结论。

输出建议表：题名/年份，用途，相关点与差异（按已读范围），优先级与阅读重点，实际来源链接，核查范围。存 `recommendations/日期-P编号.md`，注明推荐日期和查询主题。概括而非大量复制第三方摘要。

网络不可用或用户要求离线时，从本篇参考文献/已有库提出候选，准确注明二手来源与未核验项。不要编造 DOI/链接、将候选称为已核验推荐，或声称其为截至当前最新。用户提供新方向但信息不足时先给相关候选；只有选择方向真正影响结果时再询问。

# 按任务自动调度工具

这里定义调用条件，不定义不存在的 API。执行时用当前环境的工具目录/发现接口找到实际工具及参数；需要的技能从当前技能清单读取。不要把说明中的类别当作可执行工具名。

| 必要动作与触发条件 | 自动使用的能力 | 完成依据与替代 |
|---|---|---|
| 读取本地 PDF、图表、公式 | 文件读取、当前 PDF 技能/提取工具、PDF 渲染与图像查看 | 检查正文及关键页；扫描件或提取乱码时使用可用 OCR；仍不可读则标为部分文本 |
| DOI/链接身份核对、获取合法全文 | 当前浏览/检索能力、官方出版商或 arXiv 页面 | 记录真实题名、版本和已读范围；摘要页不能当成全文 |
| 找旧论文、核查已有词汇 | 本地文件搜索/读取、`library.py list`、`glossary.py lookup` | 读取登记和实际卡片/词条；无命中需考虑别名，不能用聊天记忆替代持久库 |
| 保存阅读卡、文献记录和词汇 | 本地文件写入、`library.py upsert/check`、`glossary.py ingest/check` | 成功返回编号，复查文件与索引；失败时说明哪一步未保存 |
| 推荐论文或核查领域新颖性 | 当前联网学术检索/浏览工具 | 访问真实原始来源核验；仅下载/搜索标题不等于阅读；网络不可用则给标为待核验的参考文献候选 |
| 解释性能增幅、核对表格 | 本地计算工具/可用运行时 | 保留原数、分母、单位与计算公式；不要将负 dB 数直接相除解释为提升比例 |
| 用户要求 Word/PDF 报告 | 当前相应文档/PDF 技能及生成工具 | 产物可打开、公式/表格可读；只要求普通汇报稿可用 Markdown，无须额外转换 |
| 用户要求 PPT/幻灯片文件 | 当前 presentations 技能/演示文稿工具；本地制作时先发现依赖运行时 | 生成真实演示文稿，按相应技能渲染、检查并修正；大纲不是 PPT 完成证明 |
| PPT 含原文架构/实验结果图 | PDF 图表提取/裁切、图像查看；必要时数据表/原生可编辑图表 | 来源清晰、裁切不改变含义；不要用生成图捏造论文结果 |
| 展示数学公式，或用户指出上下标/帽符号排版错误 | [公式规范](equations.md)、本技能安装检查/LaTeX 渲染脚本、可用原生公式能力 | 主动检测并安装必要免费公式依赖，输出真正公式并目视核对；SVG/图片不能冒充原生可编辑公式 |
| 需要实验对比/趋势等定量图 | 当前科研可视化技能、Python/MATLAB 绘图运行时 | 基于真实可比数据，检查轴、单位、误差定义；渲染后查看，导出所需 PNG/SVG/PDF |
| 需要方法流程/架构/文献关系图 | Mermaid、可用 Graphviz/SVG 渲染能力，或演示工具的原生可编辑图对象 | 区分原图与阅读者梳理；标明连接的含义与来源，检查箭头、符号、标签；不要把 Mermaid 文本当作已导出图片 |

先完成无需补充信息的步骤。时长、受众、模板等没有特别约束时采用汇报规范默认值并说明，不因常规工具调用反复要求用户确认。有平台权限拦截时遵循实际审批流程；技能中的“自动”不能授权绕过权限。

数学公式依赖按用户明确要求主动安装到独立目录，具体范围见公式规范；其他依赖不自动安装，不购买服务。可用工具之间优先选择足以完成任务的简单路径；仅需摘要解释时不创建 PPT，不需新资料时不进行额外检索。保存本地文件不代表允许上传到外部平台。只有用户要求远程文档/平台时才使用已授权的相应连接器。

遇到错误先根据错误信息修正参数或采用可行替代。对同一失败不要无意义地重复调用；保留已经完成的部分，交代实际限制。脚本或工具成功不证明学术判断正确，仍需查证源文。

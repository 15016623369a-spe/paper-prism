# 绘图与证据可视化

当用户要求绘图，或图能实质帮助解释方法/比较且属于本次任务时，自动使用当前可用的绘图和查看工具。普通精读不强制另画一套图，已有原图足够时直接引用并解释。

## 工具选择

| 目的 | 首选能力 | 需要保留的内容 |
|---|---|---|
| 展示原文结果或方法图 | PDF 提取/高质量裁切及图像查看 | 论文/版本/页码/图号；标明原文图，裁切不能去掉必要图例或条件 |
| 定量比较、趋势、误差、热力图 | 可用科研可视化技能及标准 Python/MATLAB 绘图工具 | 已核对源数据、单位、指标、实验口径、图注与来源；输出 PNG 及所需 SVG/PDF |
| 方法架构、训练/推理流程、概念关系 | 简单图用 Mermaid；需图片时用可用 Mermaid/Graphviz/SVG 渲染器；需可编辑 PPT 图时用演示文稿原生对象 | 可编辑图源、来源及说明；标为“依据原文重新梳理”，箭头含义明确 |
| 多论文共同点/差异与关系图 | 小规模优先比较表；关系确实复杂时用上述图工具 | 每条重要关系的依据，区分引用关系、方法继承、主题相似与个人推断 |

执行定量绘图时读取当前环境可用的科研可视化技能；该技能只适用于数据图，不用于架构/流程图。按当前任务选图与质量检查，不把数学建模竞赛的全套图数或期刊投稿规格强加给单篇阅读/组会。没有指定期刊时，阅读/汇报采用可读的通用规范即可。工具或依赖不可用时先寻找已有替代，不自动安装或虚构导出成功。

## 证据与统计口径

- 从可访问原文表格或真实数据构建绘图数据，数字提取后逐项回查；来源只有图像时优先使用原图。确需图像估读时注明“近似估读”、方法和误差限制，不当作精确原始数据。
- 跨论文数据/任务/划分/指标不同，不画暗示公平排名的共同柱状图；可用分面、表格或适用条件图解释差异。
- 缺少标准差、置信区间或样本量不捏造误差棒；缺少逐点数据不生成看似真实的收敛曲线。概念示意明确标为示意，不能混入结果图。
- 参数量、耗时、精度可展示取舍，但保留各自单位与测试条件；MSE、RMSE、dB 不混用。轴比例与基线选择须避免夸大差异。
- 方法图保留状态维度、训练/推理差别、已知/学习模块及关键依赖；推断的关系使用明显区分并在图注解释，不画成原文事实。

## 保存与检查

保存在环境交付目录，适合时用文献库 `figures/日期-P编号或主题/`，包含图像、用于重新绘制的数据/可编辑图源和简短来源说明。中间渲染文件放工作目录。组会 PPT 的数据图/明确需要可编辑的方法图遵循当前 presentations 技能；科学证据不使用生成图替代。

先明确这张图说明什么，再选最简单的有效图型。输出后自动渲染/查看实际图像，检查中文字体、裁切、标签、箭头、数值、图例及投影大小下的可读性。不能把代码、图源文本或未打开的导出文件称为已检查图。交付只链接实际存在的文件，支持格式以工具实际能力为准。

# 论文式数学公式与工具安装

论文解释、阅读卡、Word/PDF 或 PPT 涉及展示公式时读取本规范。用户要求数学排版，默认自动完成工具探测、必要安装、实际排版与目视检查。

## 排版要求

- 先回查原文页码和公式编号，核对符号、维度、上下标、帽/横线、粗体向量与矩阵、希腊字母、分数、根号和括号。LaTeX 是源代码，不是最终幻灯片上的显示形式。
- 展示公式不使用 `x_t`、`x_prev`、`x_pred`、`x_post` 这种代码字符串。写成真正的下标与估计符号；正文涉及单个符号也保持原文含义。
- 默认采用接近论文的衬线数学字体，解释文字可保留幻灯片字体。长公式在等号/加号处合理分行，不能通过缩到投影看不清来挤进文本框。编号沿用原文，不伪造编号。
- 简化公式必须明确省略了什么，保留条件索引等影响含义的标记。重新排版不等于逐像素复制原文。

## 必要依赖主动安装

用户已明确要求本技能主动安装数学公式工具。先使用可用的宿主运行时；缺少本技能公式依赖时主动运行 `scripts/setup_equations.py`，不把安装步骤交给用户。安装免费 MathJax 到用户缓存或项目独立工具目录，不安装到系统全局，不改写 Codex 捆绑运行环境。

1. 发现 Python、Node.js、包管理器及写入/联网能力。默认工具目录 `~/.cache/literature-reader/mathjax`；也可用 `LITERATURE_READER_MATH_DIR` 或 `--tool-dir` 指定可复用独立目录。沿用已验证且符合固定版本的目录，避免重复安装。
2. 运行 `python scripts/setup_equations.py --tool-dir <目录> --node <Node路径> --npm <npm路径>`。脚本固定安装 `@mathjax/src@4.1.3`，禁用依赖安装脚本，检查实际模块加载，保留版本与锁文件。需要升级时先核对官方文档，明确升级版本，不能静默追随 latest。
3. 平台有审批/网络限制时走实际授权流程，不绕过。安装失败先排查真实错误；离线可用时复用现有引擎或采用原论文清晰公式裁切，并说明实际采用方式。不要声称缺失工具已经安装。

此授权仅限任务必需的免费公式依赖；不据此安装全局 TeX 发行版、修改系统配置、购买 MathType 或上传论文。其他工具仍按原有安装规则。

## 生成与文件格式

批次 JSON 是 `{id, latex, fontSizePx, color, source}` 数组，`source` 记录论文编号、版本、页码和公式编号。执行：

```text
node scripts/render_equations.mjs batch.json output-dir --tool-dir <目录>
```

输出每条公式的自包含 SVG、MathML 和 `equations-manifest.json`，保存 LaTeX 与来源。渲染过程在安装后离线运行，不需要 API key。需要 PNG 时，先发现宿主已有 sharp，设置其包目录 `RUNTIME_NODE_MODULES` 后加 `--png`；若没有，使用环境现有 SVG 渲染器，不改写捆绑包。SVG 无外部字体/网络链接，适合论文式展示和缩放。

- 聊天/阅读卡：使用客户端支持的 LaTeX 数学块；不支持时提供真实渲染图片及符号解释。
- PPT：优先工具确实支持并能正确导出的原生可编辑公式；否则嵌入 SVG，必要时高分辨率 PNG 兼容后备，保留 LaTeX 源。图片/矢量图可移动缩放，但不能称为 PowerPoint 原生可编辑公式。用户要求可编辑公式时另行验证该能力，不能用 SVG 冒充。
- Word：用户需要可编辑公式时用原生 OMML/受支持的公式能力；MathML 是中间格式，不能把字符串直接塞到 Word 或声称它就是 OMML。明确只需展示时才可采用矢量/图片。
- LaTeX/PDF：使用对应文档编译能力。仅生成公式 SVG 不等于已编译完整论文。

最终检查每个含公式页面：渲染后目视确认无下划线原样展示、缺字、帽符号裁切、公式变形/遮挡，编号与原文一致；再检查完整 PPT 有无意外变化。公式源与图像在项目文献库保存，不写进技能示例或分享包。

工具接口依据：[MathJax 官方 Node 文档](https://docs.mathjax.org/en/v4.1/server/direct.html)。
